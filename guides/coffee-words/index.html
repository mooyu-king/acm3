All Coffee Words in Anomalous Coffee Machine 3

Quick answer

Use the search box below for mechanically useful v0.1 words. Some form names are not direct inputs: AngelDemon returns Keyword not found and must be made with Heaven + Hell in the Mixer, while Pregnant returns Drink currently unavailable and is obtained by using Life.

01

All useful words

Search forms, ingredients, scenes, and utility words

This list focuses on words with a mapped gameplay purpose, not every dictionary term the input box may accept. Search by input word or expected result, then filter by the job you want the cup to perform.

AngelDemon — keyword not found

Do not type AngelDemon directly. Make separate Heaven and Hell cups, take them to Horu’s room, and combine them in the Mixer.

Pregnant — drink unavailable

Pregnant is the resulting form name, not an available direct drink in this build. Type Life to create the cup that produces the Pregnant form.

02

Evidence first

“Accepted word” and “special result” are different claims

The v0.1 Coffee Machine checks a broad word and name list, so many inputs can create a cup. The database above is narrower: it lists words tied to a form, recipe, reset, or event in the recovered v0.1 gameplay mappings, plus a small number of clearly labeled community examples.

Source-mapped

The word appears in the recovered v0.1 synergy data with a specific result. This is stronger than an unexplained player list, but version updates can still change the route.

Community reported

The word was publicly reported by a player but has no equivalent direct form mapping in the current synergy table. It remains useful as a test input, not a guaranteed transformation.

03

Choose the right workflow

Single cup, Mixer ingredient, sequence, or trigger?

Most failed tests happen because a valid word is used with the wrong workflow. A direct form cup can be given immediately. A Mixer ingredient belongs in Horu’s room Mixer. A sequential ingredient must be drunk by the same character in the listed order. A scene trigger checks prepared character states.

01

Single-cup form

Create the cup, collect it, then use it on Horu or give it to the Neighbor.

Browse transformations →
02

Mixer ingredient

Create both cups separately, carry them home, and combine them in the Mixer.

Open Mixer recipes →
03

Sequential route

Give the first cup and then the second cup to the same character. Do not mix them.

See sequential routes →

Scene or event

These words perform a separate check. For adult scenes, prepare both character states before using Sex.
