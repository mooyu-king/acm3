Anomalous Coffee Machine 3 Fusion Recipes

Quick answer

Use Horu’s room Mixer for recipes marked with a plus sign. For routes marked with an arrow, skip the Mixer and give both cups to the same character in exact order. The current v0.1 mappings contain 16 Mixer recipes and 7 sequential transformation routes.

02

Plus sign routes

How to use the Mixer in Horu’s room

Create the first cup at the stairwell Coffee Machine, collect it, repeat for the second input, and carry both home. Open Inventory beside the room Mixer, add the two cups, and collect the fused result. The source mapping checks both orders, so Dragon + Fire and Fire + Dragon lead to the same fused cup.

What the new screenshot confirms

The Mixer accepts two separately stored cups and exposes a third output slot. It confirms the interaction order, while the searchable recipe table above supplies the mapped pair-to-result names.

Do not drink the inputs first

Using either cup on a character changes state instead of filling the Mixer slot. Keep both cups untouched until the two-input panel is open.

03

Arrow routes

Sequential transformations are not Mixer recipes

For an arrow route, use the first drink on Horu or the Neighbor and then give the second drink to that same character. The current state is part of the check. Putting Ghost and Death in the Mixer will not reproduce the mapped Ghost transformation.

Do not swap the target

If Horu receives the first cup and the Neighbor receives the second, the sequential state check is not completed. Both cups must affect the same character.

04

Fix failed combinations

Why did the fusion not appear?

Confirm the workflow before assuming the recipe changed.

01You mixed a sequential pair+

Ghost → Death, Immortality routes, and Tree growth routes belong on one character, not inside the Mixer.

02You consumed an ingredient early+

Mixer inputs must remain as cups in Inventory until both are inserted.

03You used a fused result name as a typed word+

Forms such as Death Dragon and Corrupted Zombie are produced through combinations. Typing the final name is not the mapped recipe.

04You expected a scene immediately+

A successful fusion produces a transformation cup. Adult scene triggering is a separate state-and-trigger workflow documented in the Scene Guide.
